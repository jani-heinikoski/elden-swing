
# Elden Swing

This project is a small hobby project of mine to explore a bit of Test Driven Development (TDD), Dependency Injection (DI), Maven build tool, and Java Swing for creating cross-platform GUIs.

The intention is to use and visualize in some interesting ways the [Elden Ring API](https://eldenring.fanapis.com/). I would also like to use this opportunity to design some sort of a local cache in the form of a relational database to alleviate the amount of requests sent to the API.


## Contributing

Contributions are not accepted for this project.


## Tech Stack

Note that this tech stack is subject to change during the initial stages of this project.

- Java SE 17
- Apache Maven 3.9.9
- JUnit 5 (version 5.11.4)
